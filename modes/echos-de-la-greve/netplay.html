Héberger un salon

Depuis le dossier du projet, démarre le relais avec Node.js 18 ou ultérieur.

node modes/echos-de-la-greve/netplay-server.cjs

Pour jouer sur la machine hôte, ouvre http://127.0.0.1:8080/netplay.html dans deux profils de navigateur. Pour jouer depuis deux machines du même réseau, indique l’adresse d’écoute au lancement.

macOS ou Linux

HOST=0.0.0.0 node modes/echos-de-la-greve/netplay-server.cjs

Windows PowerShell

$env:HOST = "0.0.0.0"
node modes/echos-de-la-greve/netplay-server.cjs

Ouvre l’adresse IP locale de l’hôte sur le port 8080 avant de copier l’invitation. Depuis Internet, les deux joueurs ont besoin d’un relais accessible.
